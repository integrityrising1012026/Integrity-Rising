# Integrity Rising

A repository for workbook materials, guides, and supporting assets.

## Project structure

```text
Integrity-Rising/
├── workbooks/          (Labeled workbook categories and materials)
├── system.io/          (File I/O and system operations)
├── Program.cs
├── IntegrityRising.GumroadWebhook.csproj
└── supporting files
```

## Workbook organization

The workbook files are organized by category to keep them labeled and easier to find.

```text
workbooks/
├── 01-Foundations/
├── 02-Programs-and-Challenges/
├── 03-Boundaries-and-Communication/
├── 04-Reflection-and-Insight/
├── 05-Visual-and-Reference-Materials/
└── README.md
```

### Categories

- 01-Foundations
  - foundational personal growth and recovery materials

- 02-Programs-and-Challenges
  - challenges, mood tracking, and accountability resources

- 03-Boundaries-and-Communication
  - communication guides, trauma-bonding materials, and comparison tools

- 04-Reflection-and-Insight
  - reflection, intuition, and self-awareness resources

- 05-Visual-and-Reference-Materials
  - supporting images and visual references

## System.IO

The `system.io/` folder contains file I/O operations and system utilities for the application.

This structure keeps the repository organized and makes it easier to browse workbooks by topic and manage system operations.
