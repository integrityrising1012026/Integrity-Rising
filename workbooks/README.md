# Workbooks

This repository is organized by workbook category so materials are easier to find and maintain.

## Folder structure

```text
workbooks/
├── 01-Foundations/
├── 02-Programs-and-Challenges/
├── 03-Boundaries-and-Communication/
├── 04-Reflection-and-Insight/
├── 05-Visual-and-Reference-Materials/
└── README.md
```

## Category map

- 01-Foundations
  - Reclaiming Your Path Workbook
  - foundation and identity-building materials

- 02-Programs-and-Challenges
  - 7 Day Integrity Reset Challenge
  - Daily Mood Tracker
  - challenge and accountability resources

- 03-Boundaries-and-Communication
  - Strategic Disinterest Communication Guide
  - Stages of Trauma Bonding Packet
  - Integrity Comparison Matrix

- 04-Reflection-and-Insight
  - Reflections on a Well-Lived Life
  - Navigating Abusive Dynamics Guide
  - intuition and reflective practice materials

- 05-Visual-and-Reference-Materials
  - diagrams, images, and supporting reference assets

This keeps workbooks labeled and organized by topic rather than scattered across the repo root.
